## 🎨 VISUAL DESIGN SYSTEM

### Color Palette
| Role | Hex | Usage |
|------|-----|-------|
| **Primary Emerald** | `#10B981` | Brand, CTAs, positive indicators |
| **Deep Teal** | `#0F766E` | Gradients, depth, hover states |
| **Smog Rose** | `#F43F5E` | Danger, alerts, problem state |
| **Midnight Slate** | `#0F172A` | Dark mode, night scenes, text |
| **Pure White** | `#FFFFFF` | Clean UI, highlights |
| **Warm Amber** | `#F59E0B` | Warnings, transitions, golden hour |
| **Sky Cyan** | `#06B6D4` | Clean air, water, hope states |

### Typography
- **Display/Headlines**: `Space Grotesk` / `Clash Display` - Bold, geometric, tech-forward
- **UI/Body**: `Inter` / `DM Sans` - Clean, readable at small sizes
- **Monospace/Data**: `JetBrains Mono` / `IBM Plex Mono` - Metrics, code, timestamps

### Motion Principles
| Principle | Specification |
|-----------|---------------|
| **Easing** | `cubic-bezier(0.16, 1, 0.3, 1)` (Material Design expressive) |
| **Stagger** | 80-120ms between sibling elements |
| **Duration** | Micro: 150ms | Meso: 300-500ms | Macro: 800-1200ms |
| **Physics** | Spring: `stiffness: 300, damping: 30` for UI; `stiffness: 180, damping: 15` for hero |

## 💡 CREATIVE DIRECTION NOTES

### What Makes This Cinematic
1. **Particle-to-data visual metaphor** - smog particles become information
2. **Shared element transitions** - phone, logo, charts morph seamlessly
3. **Real app UI** - not mocked up; actual codebase components
4. **Indian context authenticity** - Hyderabad references, local transit, climate
5. **Restrained color grading** - problem = cool/muted; solution = warm/emerald

### Differentiators from Generic Tech Ads
- ❌ No fake "AQI 999" fear-mongering
- ❌ No generic "download now" buttons floating in space
- ❌ No cartoon characters or illustrated style
- ✅ Real data, real app, real city
- ✅ Problem → Solution → Empowerment arc
- ✅ Community/collective impact, not just individual
